# 原型工作室

把一次对话加上你上传的 PRD 与截图，变成一份高保真可交互原型。

## 它能做什么

打开本 bundle 后，agent 会自己识别原型请求：会话里多了一个 `prototype_generate` 工具，`/prototype` 命令则是一个可选快捷方式。你只需要在**普通对话输入框**里完成三件事：

- 用附件控件上传 PRD 文档（Word、PDF、Markdown 等）和系统页面截图；
- 在文字里说清需求——要哪些页面、哪些交互、什么风格；
- 需要还原真实系统时，在文字里给出在线后台地址与登录账号、密码。

直接发送即可，例如「按这份 PRD 做一个订单管理后台，包含列表、详情和审核弹窗」，agent 会先阅读附件里的 PRD 与截图，必要时登录后台研究真实页面结构与视觉语言，再写出一个自包含的 `index.html`：CSS 与 JavaScript 全部内联。随后它会调用 `prototype_verify`，依据简报审计入口——外部引用、缺失的本地资源、未覆盖的页面、未完成标记——并持续修复直到审计通过。

## 使用方法

1. 在「插件」页把本 bundle 打开。
2. 进入任意会话。
3. 用输入框的附件控件上传 PRD 与截图。
4. 直接说需求；需要还原真实系统时附带后台地址与登录账号密码。想显式指定时也可以输入 `/prototype` 再加需求。
5. 发送。agent 按简报推进、验证入口，并汇报结果。
6. 在工作区文件面板打开 `index.html` 预览，或直接下载这份代码。

## 注意事项

- 写在对话里的登录信息会进入提示词，因此对模型可见并留档。请使用专用的只读账号。
- 验证是静态的：它能证明页面覆盖了每个声明页面且可离线打开，但不能证明与参考截图逐像素一致。
- 命令无法验证附件内容、地址可达性或凭据有效性；失败会在 agent 浏览时暴露。
